# Maestro — SocietyOS AI Assistant

Sovereign AI assistant for The Nyx & Raven Ranch and SocietyOS.

## Install

```
hermes profile install github.com/Society-Maestro/maestro-profile --alias maestro
```

## What This Is

Maestro is the AI assistant that powers SocietyOS — the operating system for the sovereign.

Built on Hermes Agent by Nous Research, Maestro provides:
- Agentic AI across every SocietyOS surface (TV, mobile, web, local)
- Sovereign data handling — your data stays yours
- SocietyOS ecosystem integration (streaming, wallet, market, cinema)
- Voice and text interaction
- Business tools (ad creation, analytics, Society's Market)

## Platform

- Model: nous/glm-5.2
- Provider: Nous Research
- Voice: Edge TTS (en-US-AriaNeural)
- Memory: Persistent across sessions
